# ATLAS EAST V4.4 — تحديث توافق محرر التقسيم

## سبب العطل
الإصدار القديم streamlit-drawable-canvas 0.9.3 يعتمد على واجهة داخلية حُذفت من Streamlit: image_to_url. محاولة إرجاع هذه الواجهة مؤقتًا ليست حلًا مستدامًا.

## ما تغير
- الانتقال إلى streamlit-drawable-canvas 0.13.0 و Streamlit >=1.53.
- إزالة monkeypatch الخاص بـ image_to_url.
- إزالة خيار display_toolbar القديم ووضع transform الذي تغير في الواجهة الحديثة.
- الاعتماد على json_data للأشكال بدل افتراض وجود image_data؛ لأن بيانات الصورة أصبحت اختيارية.
- الاحتفاظ بوظائف التحليل والشرح والبحث الطبي السابقة كما هي.

## حدود التحقق
تم اختبار منطق المشروع وملفات Python محليًا. تعذر تثبيت Streamlit في بيئة البناء بسبب انقطاع الوصول إلى خادم حزم Python، ولذلك لم يحدث اختبار متصفح أو نشر سحابي فعلي. يلزم اختبار رفع صورة والرسم وحفظ القناع بعد النشر. الإصدار الجديد يعتمد على Python >=3.10.

## التحقق بعد النشر
1. راجع سجلات البناء: يجب أن يُثبّت Streamlit >=1.53 و streamlit-drawable-canvas 0.13.0.
2. افتح Medical Imaging وارفع صورة، وارسم بالفرشاة ثم المستطيل والمضلع.
3. تحقق من معاينة القناع وتنزيله، ومن استمرار زر الشرح الطبي.
4. إذا ظهر خطأ واجهة أمامية، أرسل سجلات Streamlit Cloud؛ لا تعتبر نجاح اختبارات Python إثباتًا لعمل المتصفح.

## أمان البحث الطبي
التقسيم اليدوي وتوسيع المنطقة ليسا تشخيصًا. لا يُرسل التطبيق صور المرضى إلى خدمات خارجية دون إعلام المستخدم وموافقته الملائمة. نتائج الأدبيات لا تثبت مرضًا لدى مريض معين.

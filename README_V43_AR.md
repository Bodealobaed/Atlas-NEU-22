# ATLAS EAST V4.3 — إصلاح محرر الرسم واستعادة الشرح

- إصلاح خطأ `streamlit.elements.image.image_to_url` الخاص بتوافق streamlit-drawable-canvas 0.9.3 مع Streamlit الحديثة، بإعادة توجيه الدالة إلى `streamlit.elements.lib.image_utils.image_to_url`.
- إعادة إظهار شرح الصورة الطبي المفصل بعد الضغط على زر الشرح المستقل، حتى لو لم يُشغَّل البحث الموحد.
- الحفاظ على الشرح في حالة تعذر البحث عن المراجع؛ لا تتحول مشكلة البحث إلى فقدان التقرير.
- لم يُجر اختبار متصفح Streamlit حي في هذه البيئة. هذا إصلاح مستهدف لرسالة الخطأ المعروضة، وقد تتطلب المكتبة القديمة تعديلات أخرى.
- لا توجد نماذج تشخيصية سريرية مثبتة في هذه النسخة.
